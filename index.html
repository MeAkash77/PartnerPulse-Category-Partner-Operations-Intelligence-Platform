08 / Technical Analytics

SQL → Python → insight.

The product story is supported by an engineering workflow: structured data, analytical transformations, APIs and decision-ready visualization.

SQL / category_analysis.sql
SELECT category, COUNT(*) AS bookings, AVG(partner_utilization) AS utilization, AVG(customer_rating) AS rating FROM bookings GROUP BY category ORDER BY bookings DESC;
✓ QUERY EXECUTED · 100K+ RECORDS ANALYZED · RESULT SET READY
Python / partner_gap.py
category_gap = bookings.groupby("category").agg( demand=("booking_id", "count"), capacity=("partner_capacity", "sum"), utilization=("utilization", "mean") ) category_gap["supply_gap"] = ( category_gap.demand - category_gap.capacity )
